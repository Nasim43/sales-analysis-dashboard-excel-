# Sales Analysis Dashboard – Excel

## Project Overview
This project presents an interactive sales analysis dashboard built using Microsoft Excel. It helps explore sales performance across product categories, occasions, months, order times, and cities.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Data Analysis and Visualization

## Dashboard Features
- Revenue by Occasion
- Revenue by Category
- Revenue by Hour
- Revenue by Month
- Top 5 Products by Revenue
- Top 10 Cities by Orders
- Interactive filters for Occasion and Month

## Key Objectives
- Analyze sales performance across different categories.
- Identify products and cities with high sales activity.
- Explore revenue trends over time.
- Present business data through an interactive dashboard.

1. Download the Excel workbook.
2. Open it in Microsoft Excel.
3. Refresh the Pivot Tables if necessary.
4. Use the slicers to explore the dashboard.
